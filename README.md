# Adveture-Trails-FD-FMT

Página desenvolvida em React para compartilhamento de trilhas na região de Florianópolis. O layout foi pré-definido utilizando o Figma para garantir uma interface clara, organizada e responsiva.

Figma do Projeto: https://www.figma.com/file/zwqG2WZwANqAjHfY0bwRdJ/Wireframe-Projeto-SENAI?type=design&node-id=0-1&mode=design&t=SP8hEr3MSbxkAn4H-0

---

## 🎯 Objetivo do Projeto

Permitir que usuários visualizem trilhas cadastradas, adicionem novas trilhas e naveguem facilmente pela aplicação, com dados integrados via API.

---

## 🚀 Funcionalidades principais

- Exibição da lista de trilhas cadastradas, com atualização automática (reload da página)  
- Navegação entre páginas com React Router (`useNavigate`)  
- Cadastro de novas trilhas via formulário conectado à API (POST)  
- Exibição de trilhas em formato de cards com imagens  
- Layout responsivo para melhor experiência mobile e desktop  
- Componentização do código para melhor organização (Header, Footer, Formulário, Lista)  
- Correção e ajustes para evitar erros CORS na chamada da API  
- Deploy e ajustes para funcionar corretamente no Netlify 

---
